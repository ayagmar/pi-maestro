# Pi Maestro proof assets

Visual proof is not required to build the first complete site. Add real product media here when it becomes available.

Preferred assets:

- A representative dashboard screenshot at desktop terminal dimensions
- A short advisor → executors → review workflow recording
- A plan-review or recovery-state screenshot
- Optional architecture diagram source if a repository-derived diagram is not sufficient

Media requirements:

- Use descriptive filenames and provide a one-sentence context note with each asset.
- Keep video short and focused; provide WebM and MP4 when practical.
- Include a poster image and captions or an equivalent transcript.
- Website playback must be user-controlled and use `preload="none"`.
- The page must remain complete and understandable when media is unavailable.
